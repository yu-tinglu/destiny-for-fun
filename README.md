# destiny-for-fun 神機妙算占卜館

懷舊電腦課「文字藝術師」風格的東西方占卜小網站，單一 `index.html`，雙擊就能開，也能加進自己的 HTML 工作台。

內含 21 個工具：求籤、擲筊、每日一語、紫微斗數、塔羅、星座、今日運勢、水晶球、易經、姓名筆畫、八字、稱骨、生命靈數、梅花易數、周公解夢、盧恩符文、生肖流年、緣分配對、每日黃曆、血型配對、手相。

純屬娛樂，請勿當真。

## 重新建置
```
cd src && node build.js   # 產生 src/index.html
```
